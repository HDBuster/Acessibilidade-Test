# Acessibilidade para Game Production

## Daltonismo
Para a implementação de filtro para dicromacia, utilizei assets de Volume (Volume → Global Volume).

Criei três Volumes para: protanopia, deuteranopia, tritanopia.

Cada Volume tem "profile", dentro do componente, diferente.

O trabalho do script é apenas ligar e desligar os GameObjects de cada Volume, ou seja, para ligar um desliga os outros. Para desligar o filtro, apenas desative o três GameObjects.
